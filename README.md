# Moral Dilemma: An Ethics Choice Game

An interactive text-adventure game created for an **Ethics** course during my first year. Players navigate through different situations where their moral choices determine their final score.

## ⚖️ Behind the Project
This project was built back in my first year using straightforward Java `JOptionPane` pop-ups. It features **10 different levels**, with each stage presenting a new scenario where picking the right ethical path earns you points.

Since I wanted the game to look engaging without dealing with complex UI code, I designed all the backgrounds, assets, and animated sequences in **Canva** using a mix of static images and GIFs to bring the scenes to life.

## 🎮 Game Features
* **10 Unique Scenarios:** Face 10 distinct moral choices as you progress through the levels.
* **Score Tracking:** Your points fluctuate based on the decisions you make.
* **Canva Assets & GIFs:** Custom visual storytelling using imported graphics and animations.
* **Beginner-Friendly Logic:** Built purely on simple conditional statements and basic dialog frames.

## 🚀 How to Run the Game
To run the game from the source files inside your IDE (like Apache NetBeans):

1. Open the project folder in your Java IDE.
2. Locate the main file that launches the game (e.g., `MainMethod.java` or `EthicsGame.java`).
3. Open that file, right-click anywhere in the editor, and select **Run File** (or press `Shift + F6`).
